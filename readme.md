Raft Lite là một implementation tối giản của thuật toán Raft Consensus bằng Java.  
Hỗ trợ các thành phần core của Raft gồm: leader election, log replication, state machine apply và snapshot.

## Tính năng
- Leader election
- Log replication
- State machine apply
- Snapshot save/load
- In-process RPC
